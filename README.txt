Lista de bibliotecas requeridas e adicionais para a submissão do projeto:

1. Bibliotecas Base (Manipulação de Dados e Visualização):
   - pandas (leitura e manipulação tabular dos dados)
   - numpy (operações matemáticas e arrays)
   - matplotlib (criação de gráficos e visualização básica)
   - seaborn (visualização estatística avançada)

2. Bibliotecas Adicionais (Machine Learning e Balanceamento):
   - scikit-learn (criação de Pipelines, ColumnTransformer, RandomForestRegressor, RandomForestClassifier e GridSearchCV)
   - imbalanced-learn (importação de SMOTE para balanceamento de classes na classificação)
   - xgboost (testes de modelos alternativos de boosting de gradiente)

Comando completo para instalação das dependências:
pip install pandas numpy matplotlib seaborn scikit-learn imbalanced-learn xgboost
